webServ

Bienvenue sur votre serveur web

Un serveur HTTP léger et performant, développé en C++98.

Fonctionnalités :

  • Gestion des requêtes HTTP (GET, POST, DELETE, etc.)
  • Support des fichiers statiques (HTML, CSS, JS, images)
  • Exécution de scripts CGI
  • Configuration flexible via fichiers
  • Gestion des erreurs personnalisées (404, 500, etc.)
